# Roadmap Onyx Data Intelligence

## 3.1 — Professionnalisation GitHub
- Structure du dépôt.
- CSS/JS séparés.
- CI/CD.
- GitHub Pages.
- Documentation.

## 3.2 — Stabilisation
- Scénarios de tests de non-régression.
- Validation automatique CSV/Excel/JSON.
- Tests des exports HTML/PDF.
- Journal des erreurs utilisateur.

## 3.3 — Modularisation progressive
- Extraction de l'importateur.
- Extraction du profilage de données.
- Extraction du moteur qualité.
- Extraction des statistiques.
- Extraction du reporting.

## 4.0 — Architecture modulaire complète
- Vite ou bundler équivalent après stabilisation.
- Modules ES.
- Dépendances npm contrôlées.
- Tests unitaires statistiques.
- Tests end-to-end.
- Versioning sémantique et releases GitHub.

## 5.0 — Plateforme optionnelle
- Authentification.
- Espaces projets.
- Historique.
- Backend/API si le modèle produit le justifie.
